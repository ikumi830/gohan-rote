# ごはんローテ

いつも作る料理を「何日おきくらいに食べたいか」と一緒に登録しておくと、
前回からしばらくたった料理が「そろそろ食べたい」一覧に出てくる献立アプリ。

## 使い方

1. 「料理」タブで料理を登録する（間隔・材料・レシピURL・メモ）
2. 「ごはん」タブの「そろそろ食べたい」から作るものをタップ →「作る予定」に入る
3. 「買い物」タブに、作る予定の料理の材料が並ぶ
4. 作ったら「作った！」→ 設定した日数がたつまで一覧から消える

## Claudeに相談する（コピペ連携）

無料プランのClaudeでも使える。サーバーは不要。

1. 「ごはん」か「料理」タブの「Claudeに相談する」→「データをコピー」
2. Claudeのチャットに貼り付けて、最後にお願いを書いて送る
   - 例：「鶏肉と白菜が余ってる。どれを作ればいい？」「魚料理を3つ増やして」
3. 返事の最後に ```json のブロックが付いていたら、返事をコピーしてアプリに貼り付け
4. 「変更内容を確認」で中身を確認 →「反映する」（直後なら取り消せる）

Claudeが返せる操作：料理の追加・変更・削除、作る予定に入れる/外す、作った記録、買い物リストへの追加。
料理名が1文字でも違う操作はスキップされ、確認画面に ⚠ で表示される。

## 公開のしかた（GitHub Pages・無料）

1. https://github.com でアカウントを作り、右上の「＋」→「New repository」
   - 名前は `gohan-rote`、Public を選んで「Create repository」
2. 「uploading an existing file」をクリックし、このフォルダのファイルを全部ドラッグして「Commit changes」
   - index.html / sw.js / manifest.webmanifest / icon.svg / icon-180.png / icon-192.png / icon-512.png
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `(root)` にして「Save」
4. 1〜2分後、`https://<ユーザー名>.github.io/gohan-rote/` で開ける

## スマホのホーム画面に追加

- iPhone：Safari で開く → 共有ボタン →「ホーム画面に追加」
- Android：Chrome で開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

## データについて

- データはスマホのブラウザ内（localStorage）に保存。サーバーには送らない
- 「料理」タブの「バックアップを保存」でJSONファイルに書き出せる。機種変更時は新しいスマホで「復元する」
- アプリのファイルを更新しても、データは消えない（同じURLのまま更新すれば OK）

## 自分で直したいとき

ファイルは `index.html` 1つにまとまっている。
GitHub上でファイルを開き、鉛筆アイコンから直接編集できる。
（サンプル料理は `SAMPLES`、間隔の選択肢は `PRESETS` で検索すると見つかる）
